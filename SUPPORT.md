# Support

Armoury Crate for Linux is a community project. Support is provided on a
best-effort basis; there is no guaranteed response time or commercial support.

## Get help

1. Check the [README](README.md) for installation and dependency instructions.
2. Check the [monitoring and controls guide](docs/monitoring-and-controls.md)
   for telemetry sources and hardware limitations.
3. Search existing [GitHub issues](https://github.com/Shinkhal/armoury_crate_linux/issues).
4. If no existing report covers the problem, open a bug report with the
   information requested by the issue form.

For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue. For conduct concerns, see
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Hardware support depends on the laptop model, firmware, kernel, drivers, and
installed utilities. Include relevant versions and exact steps when asking for
help. Before sharing command output or screenshots, remove disk serial numbers,
account names, hostnames, and other information you do not want public.
