# Security Policy

## Supported versions

Security fixes are developed for the latest published release. Users should
upgrade to the latest release when one is available.

## Reporting a vulnerability

Please do not report a suspected vulnerability in a public issue or pull
request. Use
[GitHub's private vulnerability reporting](https://github.com/Shinkhal/armoury_crate_linux/security/advisories/new)
to contact the maintainers privately. Include the affected version, relevant
platform details, steps to reproduce, and the potential impact. Redact account
names, disk serial numbers, and other private information from logs.

If private vulnerability reporting is unavailable, contact the maintainer at
[shinkhalsinha@gmail.com](mailto:shinkhalsinha@gmail.com). Please allow time to
investigate and coordinate a fix before sharing details publicly.

Do not include exploit code that accesses hardware or data you do not own or
have permission to test.
